# Dashboard design

**Live Tableau dashboard:** https://public.tableau.com/app/profile/ronil.ghoghari3778/viz/Final_Project_Code_Blooded/Dashboard1?publish=yes

The original Business Intelligence case study was designed around six required visual components:

1. **Crime heatmap** — plots `LAT` and `LON` to surface geographic concentrations.
2. **Top-crime bar chart** — ranks frequent values of `Crm Cd Desc`.
3. **Monthly trend line** — aggregates `DATE OCC` by month/year.
4. **Butterfly chart** — compares male/female victim counts across age groups.
5. **Conditional-format table** — compares crime volume and case status by `AREA NAME`.
6. **KPI cards** — summarize total incidents, solved/status percentage and peak crime time.

## Interactive features

The final project documentation describes:

- Year filter
- Area Name filter
- Crime Type filter
- a **Top N** crime parameter
- dynamic KPIs that respond to dashboard filters

The original assignment also required at least six Tableau charts, a map, a bar chart, a table, a line chart, KPIs and interactive dashboard behavior.
